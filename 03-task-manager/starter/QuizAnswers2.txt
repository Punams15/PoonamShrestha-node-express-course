 Answers to the above questions are :

 1. I created a middleware function called asyncWrapper because it is a function in middleware/async.js that takes any async function and automatically catches errors.
    In controllers/tasks.js, it wraps async controller functions like getTask, createTask, etc, so I don’t need a try/catch block in every function.
    It is very helpful as all errors are sent automatically to the error-handling middleware, keeping my code cleaner which follows DRY (Don’t Repeat Yourself) principle and easier to maintain.

  const { id: taskID } = req.params;
